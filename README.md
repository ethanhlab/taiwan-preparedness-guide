## 關於本專案 / About

本專案整理適合台灣在地情境的防災與應變資訊，涵蓋個人與家庭急難救助包清單、常見災害處置流程，以及全台避難收容處所與官方聯絡資源。內容提供中文、英文、日文與韓文四種語言版本，方便在地居民與外籍人士查閱。

This repository provides a practical disaster preparedness guide tailored for Taiwan, including emergency kit checklists, response procedures for common natural disasters, and local shelter resources. Content is available in Traditional Chinese, English, Japanese, and Korean.

---

## 內容重點 / Key Features

- **災害應變指引 / Disaster Response**  
  地震、颱風、水災與火災之應變處置步驟。  
  Response steps for earthquakes, typhoons, floods, and fires.

- **緊急避難包清單與指引 / Emergency Kit Checklist & Guide**  
  個人與家庭必備物資檢查表與準備指引。  
  Essential emergency supplies checklist and preparation guide for individuals and families.

- **避難與緊急資源 / Shelters & Resources**  
  全台避難收容處所查詢與重要緊急聯絡電話彙整。  
  Shelter location lookup and emergency contact list in Taiwan.

- **防災手冊與資源 / Disaster Handbooks & Resources**  
  官方與實用防災手冊下載與延伸參考資源。  
  Official and practical disaster handbooks and reference materials.

- **緊急廣播頻率表 / Emergency Radio Frequencies**  
  全台主要防災廣播頻道與電台頻率彙整。  
  Emergency radio broadcast frequencies across Taiwan.
